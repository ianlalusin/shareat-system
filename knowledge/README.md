# knowledge/

How Shareat **operates** — customer journey, staff SOPs, store rules, policies — written in plain
English for a future AI that will guide staff and customers. Not about the code (that is `docs/`).

- Start at [INDEX.md](INDEX.md).
- Pages are added and changed only through the `knowledge-intake` skill, with Ian's OK.
- Each page carries a label block (topic, about, readers, related, updated).
- Prices, menu, hours and promos are never typed here; they live in the system.
- Moves into the database after the 1 January 2027 cutover (Ian, 2026-10-23).
