# Nightly usage recording

Each store is set up with departments — for example dine-in (servers), Foodpanda, dishwasher,
cashier, and others.

1. Every night, one staff member from each department records what that department used that
   day. This is usually the closing staff.
2. Usage is recorded in the ERP (ERP v1 today).

## If a night is missed

- The staff member is filed with an infraction.
- The next night's entry must add the missed usage, so the record is corrected.

## Monthly physical count

- The store does a physical count every month and compares it with the usage records.
- If the count and the records do not match, the manager corrects the record, investigates what
  went wrong, and takes action.
